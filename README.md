# HTML-CSS-JAVASCRIPT-PROJECT-04 | SkillHarbor Academy

A responsive, interactive, multi-page educational website for **SkillHarbor Academy**, an online learning platform, built using HTML5, CSS3, and JavaScript.

This project was developed to practice front-end web development by transforming a traditional static website into a more interactive learning platform with dynamic course discovery, saved courses, study tools, and personalized user preferences.

## 🎓 Project Overview

**SkillHarbor Academy** is a fictional online education company designed to provide learners with accessible and engaging educational content.

The platform focuses on technology-related courses, particularly web development, programming, and design.

The website allows visitors to explore available courses, filter learning content, save interesting courses, organize study activities, and compare membership plans.

The project demonstrates the practical application of JavaScript in building interactive and user-friendly educational websites.

## 🛠 Technologies Used

- **HTML5** – Semantic structure and website content.
- **CSS3** – Responsive layouts, animations, transitions, and visual styling.
- **JavaScript (ES6+)** – Dynamic interactions, DOM manipulation, and user interface functionality.
- **Local Storage** – Persistent storage of user preferences, saved courses, notes, and study progress.
- **Font Awesome** – Icons and visual elements.
- **Google Fonts** – Typography and visual consistency.

## ⚡ JavaScript Features & Enhancements

### 1. Dynamic Course Search
- Search for courses using keywords.
- Automatically filters the course catalog based on user input.
- Allows users to search for courses from different website pages.
- Displays matching courses dynamically.

### 2. Course Category Filtering
- Filter courses by their categories, including Design and Programming.
- Dynamically updates the displayed course list.
- Shows the number of matching courses.
- Provides a more organized course discovery experience.

### 3. Saved Courses / Bookmarks
- Allows users to bookmark interesting courses.
- Saves selected courses using browser Local Storage.
- Provides a Saved Courses Only filter.
- Preserves saved courses after refreshing the page.

### 4. Interactive Study Notes
- Allows learners to write and save personal study notes.
- Stores notes locally in the browser.
- Makes saved notes available after refreshing the website.
- Helps learners organize their study information.

### 5. Study Checklist
- Provides an interactive checklist for organizing learning activities.
- Allows users to mark study tasks as completed.
- Saves checklist progress using Local Storage.
- Maintains progress between website visits.

### 6. Membership Plan Selection
- Allows visitors to select their preferred membership plan.
- Saves the selected plan as a user preference.
- Provides an interactive experience when comparing membership options.

## 💾 Browser Storage & Data Persistence

The project uses the browser's **Local Storage API** to preserve selected user information, including:

- Saved courses.
- Personal study notes.
- Study checklist progress.
- Preferred membership plan.

These features provide basic persistence without requiring a backend or database.
